# Figure captions (draft)

**Figure 1.** Point extraction accuracy on the 100-chart test set (dot = pooled F1, line = 95 % CI). Test set: 100 synthetic concentration-time (PK) and exposure-response (ER) charts, 25 per group, 3,092 ground-truth marker points. A predicted point counts as correct only when it lies within the tolerance radius (0.0294 x image diagonal, the OKS > 0.5 criterion of LineEX) of a ground-truth point and is assigned to that point's legend entry; matching is one-to-one. Pooled F1 = 2TP / (2TP + FP + FN) over all points of a group. Every method received the same image, plot area and legend rectangle; v46 located the legend keys itself and the published methods received the key crops v46 exported.
